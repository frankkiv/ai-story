PART 1 · 時間線

從會聊天，
到會做事

2022 年底到現在，AI 走了四大步：先是只會回答問題的顧問，接著變成自己動手的師傅，再來是傳個訊息就辦事的管家，現在是帶著一群 AI 的包工頭。往下滑，沿著時間線看每個大小事件出現。每一步背後換了什麼技術，在它怎麼運作那頁細講。

1 · 顧問你問，它答 2 · 師傅開始自己動手 3 · 管家傳個訊息就辦事 4 · 包工頭一群 AI 一起做
這頁三個重點
  1. 四年走了四步：先是你問它答的顧問，接著是自己動手的師傅，再來是傳個訊息就辦事的管家，現在是帶著一群 AI 的包工頭。
  2. 最大的轉折在 2024 年底：AI 拿到工具，從「只會講」變成「會動手做」。
  3. 這頁只講發生了什麼事。每一步背後換了什麼技術，下一頁「它怎麼運作」會講。

各家的重要發表都有收，但 agent 工具的例子多半以作者每天在用的 Claude Code 說明，所以 Anthropic 的事件會稍微多一點。

2022
  2. 顧問你問，它答2022 年底起，AI 很會回答問題，但事情還是你自己做。
  3. 2022.11模型

    ChatGPT 推出

    很多人第一次跟 AI 聊天。它只會「講」：給你一段文字或程式碼，你自己複製、貼上、執行。

    白話說像打電話問一位博學的顧問，但他不會到你家修水管。

  4. 2023.03模型GPT-4 與第一代 Claude 推出大型模型競賽正式開始。
  5. 2023.12模型Google 推出 Gemini三強格局成形。
  6. 2024.05模型GPT-4o：即時語音與看圖AI 開始能看照片、用講的對話。
  7. 2024.09模型

    推理模型出現（OpenAI o1）

    回答前先產生一長串思考再作答。要讓 AI 自己做多步驟的事，這是前提。

    白話說從搶答的學生，變成先打草稿再寫答案的學生。

  8. 師傅開始自己動手2024 年底起，AI 拿到工具，直接在你電腦裡做事。
  9. 2024.10Agent

    Claude 學會操作電腦（computer use）

    看螢幕、移動滑鼠、打字。還很慢、常按錯，但 AI 的手第一次伸進了電腦裡。

  10. 2024.11Agent

    Anthropic 推出 MCP

    讓任何工具都能用同一種格式接上 AI，後來 OpenAI、Google 也採用。

    白話說AI 的 USB-C，什麼工具都插得上。

  11. 2024.12中國DeepSeek V3671B 參數的 MoE 模型，以很低的訓練成本做出接近頂尖的表現。這個成本只算正式訓練那一次，不含前期研究和實驗。
  12. 2025.01中國

    DeepSeek R1 震撼市場

    開放權重的推理模型，表現逼近美國旗艦，輝達股價單日重挫。很多人第一次發現中國模型追得這麼近。

  13. 2025.01AgentOpenAI OperatorAI 自己開瀏覽器幫你訂位、填表。網頁版的「動手」。
  14. 2025.02Agent

    Claude Code 預覽版、vibe coding

    AI 直接在你電腦裡讀檔、改檔、跑測試、修錯。Karpathy 提出「vibe coding」：用講的就能做軟體。

    白話說顧問變成請到家裡的師傅。

  15. 2025.04AgentOpenAI Codex CLI終端機裡的 coding agent 變成各家標配。
  16. 2025.05AgentClaude Code 正式推出同時推出 Claude 4 系列。
  17. 2025.06AgentGoogle Gemini CLI三大廠都有了自己的終端機 agent。
  18. 2025.07AgentChatGPT agentChatGPT 裡直接有一台虛擬電腦，能上網、做簡報、整理試算表。
  19. 2025.07AgentClaude Code subagents主 agent 可以把子任務交給各自有乾淨 context 的子 agent，做完只回報結果。多 agent 協作的起點。
  20. 2025.08模型GPT-5OpenAI 把快速回答的模型和推理模型合成一個系統，由路由器自動決定要不要深想。
  21. 2025.09中國Anthropic 停止服務中國控股公司理由之一是防止蒸餾。
  22. 2025.10AgentAgent Skills把工作流程寫成資料夾、按需載入。「調教 AI」變成管理文字檔。
  23. 管家傳個訊息就辦事2025 年底起，從聊天軟體就能叫 AI 做事。
  24. 2025.11模型Gemini 3 與 Claude Opus 4.5同一個月兩家換代。Opus 4.5 在寫程式考試 SWE-bench Verified 拿到 80.9%，是第一個過八成的模型；Gemini 3 Pro 是 76.2%。
  25. 2025.11Agent「小龍蝦」誕生工程師 Peter Steinberger 的個人專案，吉祥物是一隻龍蝦：在 WhatsApp 傳訊息，就能叫家裡電腦上的 AI 做事。後來改名 OpenClaw。
  26. 2026.01AgentClaude Cowork：給不寫程式的人用的 agent在桌面版 Claude 裡指定一個資料夾，它就能自己整理檔案、做表格、寫報告，背後是和 Claude Code 同一套 agent 架構。
  27. 2026.01Agent

    OpenClaw 爆紅

    它原本叫 Clawdbot，先改名 Moltbot，1/30 定名 OpenClaw，短短幾天拿到十萬顆星。也冒出假擴充套件、詐騙幣和 prompt injection。

    白話說用 LINE 傳訊息給管家，但太老實的管家也可能被騙。

  28. 2026.02Agent

    Remote Control：手機遙控電腦上的 AI

    程式和檔案留在電腦上，手機只是遙控器，訊息經 Anthropic 中繼。

  29. 2026.02中國

    蒸餾指控公開化

    OpenAI 向美國眾議院提交備忘錄；Anthropic 點名 DeepSeek、Moonshot、MiniMax，約 2.4 萬個帳號、1,600 萬次對話。

  30. 包工頭一群 AI 一起做2026 年起，一個人帶一支 AI 團隊。
  31. 2026.02AgentAgent Teams隨 Opus 4.6 推出：Claude Code 可以開一組 agent 分工，彼此直接傳訊息協調，不必每件事都經過主 agent。
  32. 2026.03Agent從手機傳訊息派工作，變成正式功能Anthropic 的 Dispatch、Channels 等功能，讓你不用自己架設，就能從手機或聊天軟體把工作交給電腦上的 AI。
  33. 2026.04模型Claude Mythos Preview 與 Project Glasswing4/7 公布：Anthropic 說它找資安漏洞的能力強到不適合直接公開，先只給資安合作夥伴用來修補漏洞。它是後來 Fable 的前身。
  34. 2026.04基礎設施IEA：資料中心用電一年 +17%2025 年 AI 為主的資料中心用電成長 50%，全部資料中心用電 2030 年預估翻倍。
  35. 2026.06模型Claude Fable 5在 SWE-bench Verified（讓 AI 修 500 個真實軟體問題的考試）拿到 95%，這份考卷快被考滿了。它和只給資安夥伴用的 Mythos 是同一個模型，多了一層防護。6/9 發表，6/12 起因美國出口管制命令全面暫停服務；6/30 商務部撤銷命令，7/1 恢復。
  36. 2026.07模型GPT-5.6 分三級、Claude Opus 5OpenAI 開始把同一代模型分成 Sol（最強）、Terra（均衡）、Luna（快又便宜）三級；兩週後 Anthropic 推出 Opus 5。
  37. 2026.09模型Claude Fable 5.1 與 Mythos 5.19 月初推出，Fable 的第一次小改版，評比頁的廠商表用的就是它。
  38. 2026.09中國美國情報機關聯合點名六家，中國反駁NSA、CISA、FBI 9/8 發布聯合警示，點名六家中國實驗室蒸餾美國模型；中國商務部隔天回應，說指控沒有事實和法律依據。
  39. 2026.09模型GPT-6、Claude Opus 5.5、Gemini 4九月三家幾乎同時換代：GPT-6 Astra（9/3）、GPT-6 Sol 和 Luna 與 Opus 5.5 同一天（9/22）、Claude Sonnet 5.5（9/28）、Gemini 4 Argon（9/30）。
  40. 2026.09Agent

    多 agent 變成產品功能

    Claude Code 9/17 推出新版 Projects：一個總管 agent 跟你對話，把工作分給各自有 context 的 thread。

    白話說你只跟包工頭講需求，他找水電、木工分頭做。

  41. 2026.10中國Anthropic 稱反蒸餾見效Anthropic 第二份報告（廠商自報）：蒸餾者拿到的資料減少約 90–99%。
  42. 2026.10模型Claude Haiku 5.5、Gemini 4 CarbonHaiku 5.5（10/7）每百萬 token 只要 $0.10／$0.50；Google 的 Gemini 4 Carbon（10/28）在 Argon 之上，先只開放給資安防禦者。
  43. 2026.11模型Claude Fable 5.2 與 Mythos 5.211/9 推出，第三方綜合指數排到第一，API 價格從每百萬 token $10／$50 降到 $8／$40。
  44. 2026 —基礎設施記憶體與硬碟缺貨HBM、DRAM、硬碟產能被 AI 資料中心搶光，下一個瓶頸是電和硬體。
