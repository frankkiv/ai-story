開場

你坐在電腦前，打開 Claude Code

你突然好奇：大家天天在講的 AI，究竟是什麼？於是在 Claude Code 裡打下「AI 究竟是什麼？」。接下來每一步，舞台上方的「你的畫面」會告訴你這時候螢幕上看到什麼，下面的地圖則是同一時間背後真正發生的事。

第一章

你在電腦前問了一句話

第 1 步

Enter 按下去，先接手的是你電腦上的程式

你打字的地方是 Claude Code，一個裝在你電腦上的程式，叫做客戶端（client，負責跟伺服器講話的那一端）。這時候還沒有任何東西離開你的電腦。

第 2 步

它先翻你電腦上的檔案

客戶端會讀進記憶檔 CLAUDE.md（你的專案規範和偏好）、skills 清單、MCP 工具的說明，以及這段對話之前的完整紀錄。這些檔案都放在你的硬碟上。

白話說出門找顧問之前，先把筆記本、公司規定和以前的往來信件都收進包包。

第 3 步

照固定順序，打包成一整包

順序是工具說明（其中一項是網路搜尋）、系統規則（含 skills 清單和今天的日期）、記憶、對話紀錄，最後才是你剛打的那句。整包寫成一份 JSON，準備送到 API 的 /v1/messages。不常變的放前面，下一章的快取會用到這個順序。

第二章

你等待的那一兩秒

第 4 步

出門之前，先上鎖

整包透過 HTTPS 送出。HTTPS 是加密的連線，路上經過的網路設備看不懂內容。你的電腦只往外連，不需要打開任何讓別人連進來的門。

白話說信裝進上鎖的保險箱再交給快遞，快遞只知道送去哪，不知道裡面寫什麼。

第 5 步

離開你家，跨海到遠端機房

上了鎖的整包從你家的 Wi-Fi 路由器出發，經過電信業者的網路，走海底電纜，送到 Anthropic 使用的雲端資料中心。以機房在美國西岸為例，單程大約 1 萬公里，訊號來回一趟約 0.1 到 0.2 秒。

從這一步開始，資料已經不在你的電腦上。接下來的驗證、計算和生成，全部發生在遠端。

白話說像寄國際快遞：從你家門口出發，過海送到另一個國家的大樓。只是網路快得多，眨個眼就能來回。

第 6 步

伺服器前台先驗明正身

API（程式之間講好的收件窗口）先確認你的帳號或金鑰、檢查用量額度，再把這一包分給一台有空的 GPU 機器。

第 7 步

文字被切成 token，變成一串數字

模型不直接讀字，它讀的是 token（模型處理文字的最小單位，可能是一個字、半個詞或一段英文）。每個 token 對應一個編號。圖上的切法和數字只是示意。

白話說把一句話拆成一塊塊積木，每塊積木背後有一個號碼。

第 8 步

跟上次一樣的部分，直接用存好的

伺服器會從頭比對這一包跟上一輪送來的是否一字不差。相同的前綴，直接拿暫存的計算結果（prompt cache），只有新的部分要現算。快取預設存活約 5 分鐘，太久沒用就要整包重算。

白話說熟客五分鐘內再點，廚房不用重新備料。記得的是備好的料，廚師的手藝沒變。

第 9 步

模型先把整包讀一遍

整包被送進 GPU（擅長同時做大量計算的晶片）上的模型。模型先把所有 token 一口氣讀過一遍，這叫 prefill。每個 token 讀完都會留下一份中間結果，叫 KV cache；之後每生出一個新字，都要回頭查這些筆記，不必從頭重讀。上一步的 prompt cache，存的就是這種筆記。

白話說考試前先把題目和參考資料全看一遍，重點抄在便條上，作答時看便條就好。

第 10 步

同一個模型，一層一層往上算

回答不是好幾個模型合作拼出來的。它是一個模型，裡面疊了數十層結構相同的計算層（各家實際層數多半沒公開，圖上是示意）。

每一層都會回頭看前文所有 token，判斷哪些跟現在最相關（這叫 attention），再把理解往上一層傳。一般認為越上面的層處理越抽象的東西，像是「這句在問定義」。圖上每層寫的內容只是幫助想像，實際上沒辦法這樣一層一層讀出來。

白話說像公文一層層往上簽，每一關都加一點判斷，最後一關才拍板。

第 11 步

最後一層猜下一個字

最上面一層會替所有可能的 token 打分數，換算成機率。在「AI 是」後面，「一種」的機率可能最高，「指」次之（數字是示意）。模型挑一個接上去，再拿整串去猜下一個，回答就這樣一個字一個字長出來。這叫推論。

整個過程中，模型的權重（它從訓練學到的全部內容）一個數字都不會改。

白話說像玩文字接龍，每次只接一個字，接完再看整串想下一個。

第三章

要不要查，然後回答你

第 12 步

要不要上網查？模型自己判斷

模型不會每題都上網。整包最前面的工具說明裡有「網路搜尋」，你接上的 MCP 連接器也在裡面，用不用、用哪個，都由模型決定。「AI 究竟是什麼？」是穩定的概念，訓練時已經讀過大量相關資料，直接回答就好。

如果你問的是「今天有什麼 AI 新聞」，它學過的資料停在某個日期，這時它就會選擇呼叫搜尋工具。模型平常怎麼跟上新的事，寫在 它怎麼運作 · 最新的事從哪來。

白話說問老師什麼是光合作用，他直接講；問今天的頭條，他才會去翻報紙。

第 13 步

如果要查，搜尋結果加進整包

這一題用不到，但值得看一次。假設你問的是今天的新聞：模型先輸出一段「我要搜尋」的請求（tool_use），Anthropic 的伺服器代為上網搜尋，把找到的網頁摘要和網址加到整包後面，模型再讀一次（第 9 到 11 步）才寫答案，答案會附上來源連結。

讀檔、跑指令這類工具不一樣，它們會回到你的電腦上執行，做完再把結果加進整包送一次。這樣來回直到模型不再要工具，就是 agent 迴圈。

第 14 步

邊算邊傳回來

答案用串流（streaming）的方式送回，算出一小段就傳一小段，沿著同一條加密連線回到你的電腦。所以你看到的字是一段一段跳出來，不是等全部寫完才出現。

第 15 步

做完了，整段存回你的電腦

這一輪的問題和回答（有查的話，連同搜尋結果）都寫進你電腦上的對話紀錄（~/.claude/projects/ 裡的 .jsonl 檔）。下次你接著問，客戶端會再把它整份讀出來重送。

白話說AI「記得」上次聊什麼，是因為你的電腦把紀錄留著，下次再附上去。

第四章

你拿起手機繼續

第 16 步

你離開電腦，手機上看到同一段對話

你出門了，打開手機的 Claude App，看到的是剛剛那一段對話。這是因為開了 Remote Control：你的電腦會主動連到 Anthropic 的中繼服務，手機的 Claude App 也連過去。中繼只負責把兩邊的訊息互相轉送，連線期間也會存一份對話紀錄給手機看。它不跑你的程式，也碰不到你的檔案。

白話說手機像遙控器，電腦像電視，中間有個轉接站幫忙傳訊號。

第 17 步

手機打的字，經過中繼交給電腦

你在手機上追問「那今天有什麼 AI 新聞？」，訊息先到中繼，再轉給你的電腦。電腦把它加到整包最後面，從第一章重新走一遍；這一次，模型會選擇上網查。如果 Claude Code 要先問你允不允許，手機上的「允許」按鈕也是用同一條路把你的決定送回電腦。所以電腦要保持開機，檔案一直留在家裡。

所以

你看到的四個畫面，背後是同一張圖

在你的電腦上組合，送到遠端的模型；模型讀整包、一層層算、一個字一個字猜，需要時才上網查；答案邊算邊回來，再透過中繼同步到手機。一路上變多的只有紀錄，模型本身一個位元都沒有改。

想自己動手調看看每一層，可以到 它怎麼運作 · context 模擬器；模型怎麼跟上新的事，在 最新的事從哪來；同步的三種用法比較在 手機與電腦同步。

以 Claude Code 為例。token 的切法與編號、模型層數、候選字的機率都是示意；台灣到美國西岸的距離與延遲為估算，實際路線與機房位置會不同；prompt cache 時效以官方文件為準。更完整的技術細節在 它怎麼運作。
