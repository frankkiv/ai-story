PART 4 · 追趕與蒸餾

中國 AI 怎麼追上來，
美國廠商怎麼防

2024 年底，中國最好的模型在寫程式考試上還落後美國旗艦一大截；到 2026 年，差距縮到只剩幾分，而且多數是開放權重、價格便宜很多。工程創新是主因之一，「蒸餾」別人的模型則是最有爭議的那一個。

01 · 崛起

幾個關鍵角色

2025 年 1 月 DeepSeek R1 推出，是很多人第一次發現中國模型已經追到這麼近。之後幾家公司輪流推出開放權重的強模型。分數變化見時間線頁的能力曲線。

DeepSeek · 深度求索V3（2024.12）、R1（2025.01）V3 是 671B 參數的 MoE 模型，每個 token 只啟用 37B；技術報告寫完整訓練用了 278.8 萬 H800 GPU 小時。R1 展示了用強化學習就能讓模型學會推理，論文後來登上 Nature。
Moonshot · 月之暗面Kimi K2 系列主打 agent 和寫程式，開放權重。K2 Thinking 之後的版本在 SWE-bench 上逼近美國旗艦。
Alibaba · 阿里巴巴Qwen（通義千問）從小模型到旗艦都有，開放權重的版本在全球開發者社群用得很廣，也常被拿來當其他模型的基底。
Zhipu · 智譜GLM 系列GLM-4.5 之後主打 agent 能力，也是開放權重。
MiniMaxM 系列主打 agent 與寫程式，價格非常低。
02 · 為什麼追得這麼快

四個原因，只有一個有爭議

原因 1 · 工程創新

在有限算力下把效率榨乾

MoE（每次只啟用一小部分參數）、MLA（壓縮注意力需要的記憶體）、低精度訓練、以強化學習訓練推理。很多做法後來被全世界的實驗室參考。

原因 2 · 出口管制的反作用

買不到最好的晶片，只好更省

美國限制先進 AI 晶片出口到中國，逼得中國團隊在演算法和系統上下功夫。這是它們的效率特別突出的原因之一。

原因 3 · 開放權重與低價

全世界都能下載、拿來改

開放權重讓全球開發者一起用、一起回報問題，生態跑得很快；API 價格也常常只有美國旗艦的幾分之一。

原因 4 · 有爭議

蒸餾別人的模型

2026 年初，Anthropic 和 OpenAI 都公開指控部分中國實驗室，用大量帳號向它們的模型提問，把回答拿去訓練自己的模型。下面細講。

白話說一個學生成績進步很快，可能是他很會讀書、很省時間，也可能是他偷偷抄了學霸的筆記。現實裡往往兩者都有，只看其中一面都不公平。

03 · 蒸餾是什麼

讓學生模型模仿老師模型的回答

蒸餾（distillation）本身是很普通的技術：拿一個大模型（老師）的輸出當教材，訓練一個比較小、比較便宜的模型（學生）。各家都用它把自己的大模型壓成小模型，DeepSeek 也把 R1 的推理能力蒸餾進較小的模型。問題出在「老師是別人家的，而且對方明文禁止」。

STEP 1準備題目針對想要的能力（寫程式、用工具、推理）大量產生 prompt。
STEP 2問老師模型透過 API 送出，常常要求它「一步一步寫出推理過程」。
STEP 3收集回答把題目、答案、推理過程整理成訓練資料。
STEP 4訓練學生用這些資料做監督式微調；或拿老師當評分者，做強化學習。
結果學生學到老師的「解題風格」不用花老師那麼多錢做資料和訓練，就學到相近的能力。
蒸餾的訓練資料長這樣（示意）jsonl
{"prompt": "修好這個 race condition…",
 "teacher_reasoning": "先看鎖的範圍…第二步…",  // 最值錢的部分
 "teacher_answer": "把 mutex 移到…"}
{"prompt": "用這三個工具查出…",
 "teacher_tool_calls": [ … ],
 "teacher_answer": "…"}

為什麼推理過程最值錢？只有答案，學生只能背；有完整的思考步驟，學生才學得到「怎麼想」。所以反蒸餾的重點之一，就是不讓完整推理過程被拿走。

白話說蒸餾就像請學霸寫一大疊題目的詳解，拿去給自己的學生練。學霸自己的學校這樣做很正常；別的補習班用假身分大量來要詳解，就是另一回事了。

04 · 公開的指控

從懷疑到點名

以下都是提出指控的公司自己的說法。截至寫作時，本頁沒有找到被點名公司的詳細公開回應。

  1. 2025.01DeepSeek R1 推出後OpenAI 與 Microsoft 傳出調查是否有人透過 API 蒸餾 OpenAI 的模型。
  2. 2025.09Anthropic 收緊銷售限制不再提供服務給由中國等地區控制的公司（含持股超過 50% 的子公司），理由之一就是它們可能用蒸餾來發展自己的 AI。
  3. 2026.02.12OpenAI 給美國眾議院中國特別委員會的備忘錄指 DeepSeek 相關人員開發繞過存取限制的方法，透過「遮蔽來源的第三方 router」取用美國模型的輸出。
  4. 2026.02Google表示曾有單一行動對 Gemini 送出超過 10 萬個 prompt 試圖複製模型，稱之為智慧財產竊取。
  5. 2026.02.23Anthropic 發布報告，點名 DeepSeek、Moonshot、MiniMax約 2.4 萬個詐欺帳號、超過 1,600 萬次對話。依 Anthropic 統計：MiniMax 超過 1,300 萬次、Moonshot 超過 340 萬次、DeepSeek 超過 15 萬次。目標是 agent 寫程式、工具使用、推理，DeepSeek 還被指拿 Claude 當強化學習的評分者。
  6. 2026.10.12Anthropic 第二份報告說新防線讓蒸餾者拿到的資料減少約 90–99%，封鎖了數萬個帳號，並新增點名智譜蒸餾資安相關能力。
05 · 攻防技術細節

攻方怎麼抄，守方怎麼擋

把公開報告裡描述的手法兩兩對照。每一招攻擊，後面接著對應的防禦。

攻方：蒸餾者守方：模型公司
ATTACK · 規模大量假帳號 + 代理網路用數萬個帳號分散流量，背後是 Anthropic 稱為「hydra cluster」的代理網路，單一網路就同時管理超過 2 萬個帳號，封掉一個馬上換一個。
vs
DEFENSE · 偵測行為指紋與分類器從 IP 關聯、請求中繼資料、基礎設施特徵把帳號串成同一個行動；用兩階段分類器辨識蒸餾模式，Anthropic 說誤判率低於 0.1%。
ATTACK · 隱藏來源第三方 router 與轉售商不直接用自己的帳號，而是透過轉接 API 的第三方服務，讓請求看起來來自別人。
vs
DEFENSE · 身分帳號驗證與地區限制對教育、資安研究、新創這類容易被冒用的帳號加強驗證；不對中國控制的公司提供服務；和雲端業者、其他實驗室交換情報。
ATTACK · 套推理要求模型寫出完整思考過程設計 prompt 讓模型把推理一步步寫出來，或事後重建推理軌跡，因為這是最有教學價值的部分。
vs
DEFENSE · 推理不外流只給摘要、限制推理去向把推理過程摘要後才顯示，或只讓發出請求的組織看到。Anthropic 的實驗：用完整推理訓練的學生 SWE-bench 80.4%，只用摘要則掉到 71.8%。
ATTACK · 針對能力只抄最貴的那幾項大量集中在 agent 寫程式、工具使用、電腦操作、評分這類最難自己做資料的能力。
vs
DEFENSE · 成本封禁、限流、照收費對重複違規者加嚴限制、直接封號，被擋下的請求也照樣收費，讓抄的成本變高。
ATTACK · 研究前沿任何看得到的輸出都能當教材只要 API 回傳文字，理論上就能拿去訓練，這是蒸餾很難完全防住的根本原因。
vs
DEFENSE · 研究前沿反蒸餾取樣（antidistillation sampling）2025 年的一篇論文提出：稍微調整模型挑下一個 token 的機率，讓推理軌跡拿去訓練別的模型時效果變差，但對一般使用者的品質影響很小。目前還在研究階段。
只給摘要，學生能學到多少？（Anthropic 2026/10 實驗）
用完整推理訓練80.4%
只用推理摘要訓練71.8%

學生模型在 SWE-bench Verified 的分數。刻度 0–100%。

06 · 爭議在哪

這件事沒有表面上那麼黑白分明

合不合法

違反使用條款，不等於觸法

各家都禁止用輸出訓練競爭模型，用假帳號也違反條款。但「模型輸出能不能受著作權保護」在各國都還沒有定論，所以多半是商業與政策問題。

雙重標準？

美國模型也用了別人的資料

批評者指出，大模型本身就是用網路上大量別人的內容訓練的。支持者則認為，用假帳號系統性地取走競爭對手的成果，性質不同。

安全與政策

蒸餾也能繞過出口管制

Anthropic 認為蒸餾會削弱晶片出口管制的效果，而且蒸餾出來的模型不一定保留原本的安全防護。這讓它從商業糾紛變成地緣政治議題。

比較持平的結論：中國實驗室確實有很多真本事，這從它們公開的論文和開放權重模型就看得出來；同時，被點名的蒸餾行為規模很大，美國廠商也正在用技術和政策反制。兩件事可以同時成立。

白話說反蒸餾就像名師上課只寫重點、不發完整詳解，還會認出那些換了一百個假名來旁聽的人。擋得了大部分，但擋不了全部。

07 · 家人會問

我可以用中國的 AI App 嗎？

可以用，但要知道三件事

資料存在哪。用中國公司自己的 App 或網站，對話通常存在中國的伺服器上，受中國法律管轄，依法可能要配合政府調查。台灣的政府機關 2025 年起就禁止公務使用 DeepSeek。

內容會被審查。問到政治敏感的題目（例如台灣、天安門），回答常會迴避或照官方說法。查資料、學知識時，這類題目別只問它。

App 和模型是兩回事。很多中國模型是開放權重，可以由其他公司架在別的國家的伺服器上提供。這時資料不會經過原廠，但模型本身訓練出來的審查傾向還在。

那我該怎麼做？

不要放個人資料、工作文件和帳號密碼；政治、歷史議題多看幾個來源；手機 App 安裝時留意它要的權限。這幾點其實對任何 AI App 都適用，只是用中國 App 時更要注意。
